# Deferred operational tooling — v0.3.0

This is a future-scope register, not implemented capability or roadmap advancement. v0.2.0 is the runnable foundation with explicit data/security/toolchain applicability; it provides no generic package installer. Project-local tools and stronger gates remain in place. A = direct extraction, B = generic after parameterization, C = local template/reference, D = local infrastructure, E = business/provider-specific, F = historical, G = genuinely new opportunity. No fixed test count, provider brand, DB schema, service stack or local roadmap is a generic mandate.
